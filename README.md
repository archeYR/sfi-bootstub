## SFI-Bootstub

Bootstub is a Linux bootloader that is used on various Intel MID devices. This fork focuses on bringing the compatibility with newer Linux kernels as well as standard Multiboot images to the SFI devices. It also supports logging to linear framebuffer setup by firmware for feedback and debugging. Note that for generating a boot image with SFI-Bootstub, you have to use modified mkboot tool from https://github.com/archeYR/intel-ifwi-study.
